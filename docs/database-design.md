# Diseño de Base de Datos

Este documento describe el diseño físico de la base de datos utilizada por el sistema, alineado con el modelo de dominio definido previamente.

## Tablas Principales
- Users
- Tasks

## Convenciones de Nomenclatura
- Tablas en singular
- Columnas en PascalCase
- Primary Keys como Id (uniqueidentifier)
- Foreign Keys como <Entidad>Id
